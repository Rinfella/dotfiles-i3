# kitty

Fast, GPU-accelerated terminal emulator configured as primary terminal in i3wm.

## Prerequisites
- `kitty`
- JetBrains Mono Nerd Font

## Keybinds (in kitty)

### Windows & Splits
| Key | Action |
|-----|--------|
| `Ctrl+Shift+Enter` | New split window |
| `Ctrl+Shift+w` | Close split window |
| `Ctrl+Shift+]` / `[` | Next / previous split window |

### Tabs
| Key | Action |
|-----|--------|
| `Ctrl+Shift+t` | New tab |
| `Ctrl+Shift+q` | Close tab |
| `Ctrl+Shift+Right/Left` | Next / previous tab |

### Font & Layout
| Key | Action |
|-----|--------|
| `Ctrl+Shift+equal` | Increase font size |
| `Ctrl+Shift+minus` | Decrease font size |
| `Ctrl+Shift+backspace` | Reset font size |
| `Ctrl+Shift+l` | Switch layout |
| `Ctrl+Shift+f5` | Reload `kitty.conf` live |

### Scrolling & Copy
| Key | Action |
|-----|--------|
| `Ctrl+Shift+Up/Down` | Scroll line up/down |
| `Ctrl+Shift+PageUp/PageDown` | Scroll page up/down |
| `Ctrl+Shift+c` | Copy to clipboard |
| `Ctrl+Shift+v` | Paste from clipboard |
