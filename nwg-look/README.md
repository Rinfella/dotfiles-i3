# nwg-look

GTK3/GTK4 settings and theme editor for tiling window managers.

## Prerequisites
- `nwg-look`

## Features
- Manages GTK themes (Catppuccin / Sweet Dark), icons, cursor themes, and font antialiasing across all GTK2/3/4 applications without requiring a full desktop environment.

## Usage
```bash
nwg-look                # launches GTK theme configurator GUI
```
