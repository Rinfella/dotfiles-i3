# alacritty

GPU-accelerated terminal emulator configured as secondary / fallback terminal.

## Prerequisites
- `alacritty`
- JetBrains Mono Nerd Font

## Configuration Highlights
- **Font:** JetBrains Mono Nerd Font (size 10.5)
- **Theme:** Catppuccin Mocha / Sweet Dark matching the rest of the desktop
- **Padding:** Subtle inner padding for clean window tiling
- **Opacity:** Matches compositor settings

## Controls
```bash
# Launch alacritty
alacritty

# Launch with custom command
alacritty -e btop
```
