# xsettingsd

Lightweight XSETTINGS daemon for X11 applications.

## Prerequisites
- `xsettingsd`

## Purpose
Provides instant GTK theme, font antialiasing (`RGBA`, `Hinting: 1`), and icon theme configuration to running GTK+ and X11 programs without a heavy GNOME/XFCE settings daemon.

## Configuration
- `xsettingsd.conf` — Specifies GTK Net/ThemeName, Net/IconThemeName, and Xft parameters.
